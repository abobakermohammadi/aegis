# Maintainers

Aegis is currently maintained by:

- **Abobaker Mohammadi** — primary maintainer — [@abobakermohammadi](https://github.com/abobakermohammadi)

## Maintainer responsibilities

The primary maintainer is responsible for:

- project direction and release decisions;
- reviewing pull requests and proposed behavior changes;
- triaging reproducible bug reports;
- keeping verification, benchmark, security, and contribution documentation aligned with shipped behavior;
- evaluating security reports and coordinating fixes;
- maintaining the release history and compatibility expectations;
- refusing unverifiable performance or adoption claims in project documentation.

## Contribution model

Aegis is early-stage and currently single-maintainer. External contributions are welcome through pull requests and issues. Behavior changes should include reproducible evidence and tests as described in [`CONTRIBUTING.md`](CONTRIBUTING.md).

Security-sensitive reports should follow [`SECURITY.md`](SECURITY.md) rather than public issue discussion before remediation.
